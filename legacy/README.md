# Inactive legacy reference

These files are retained for reference. Bootstrap does not link them, the Zsh
loader does not source them, and legacy/bin is not added to PATH.

Some helpers upload files to outside services, store plaintext credentials,
interpolate strings into shell commands, delete Git branches, or modify macOS.
Review and repair individual files before reusing them. Do not source or run
this directory as a bundle. No credentials or cache from the old Mac belong here.
